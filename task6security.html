1. What is the minimum recommended length for a strong password?
Correct! 12 characters is the current minimum recommendation for strong passwords.

2. Which of these is NOT a recommended method for creating strong passwords?
Correct! Simple letter substitutions (like @ for a) are easily cracked by modern algorithms.
Incorrect. Letter substitutions create predictable patterns that are easy for hackers to guess.
3. What does the "3-2-1" backup rule recommend?
Correct! The 3-2-1 rule is a gold standard for data backup strategies.
Incorrect. The 3-2-1 rule applies to backups, not account recovery.
4. Which of these is the most secure way to handle sensitive documents?
Correct! Encryption provides the strongest protection for digital documents.
Incorrect. While password protection helps, encryption is much more secure.
5. What should you do before connecting to public Wi-Fi?
Correct! Both using a VPN and disabling file sharing are essential for public Wi-Fi safety.
Incorrect. You should do both - use a VPN AND disable file sharing.
