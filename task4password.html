TASK 4: MITIGATING PASSWORD RISKS

Even with strong passwords, security incidents can occur. This task teaches you how to respond to breaches and maintain ongoing password hygiene.

Check If Your Accounts Have Been Compromised

Visit Have I Been Pwned to check if your email or passwords appear in known data breaches.

Password Incident Response Scenarios

Scenario 1: You receive a breach notification email

"We've detected suspicious activity on your account. Please reset your password immediately by clicking this link..."

Proper Response:
  1. Don't click links in the email (could be phishing)
  2. Manually navigate to the official website
  3. Change your password directly on the site
  4. Enable 2FA if not already active
  5. Check for similar passwords on other sites
Scenario 2: You accidentally used a work password on a personal site

You realize you've reused your corporate password on an external gaming forum that just announced a breach.

Proper Response:
  1. Immediately change your work password
  2. Report the incident to your IT security team
  3. Review account activity for suspicious access
  4. Never reuse work passwords elsewhere

Ongoing Password Maintenance Checklist

✓ Monthly: Audit password manager for weak/duplicate passwords
✓ Quarterly: Update master password and 2FA methods
✓ Bi-annually: Review emergency access contacts
✓ Immediately: Change passwords after any suspected breach

Enterprise Password Policies

  • Minimum 12-character passwords for all systems
  • 90-day password rotation for privileged accounts
  • Multi-factor authentication required for remote access
  • Password sharing only through approved vaults
  • Automated alerts for password reuse attempts
Password Recovery Best Practices
  • Use memorable answers for security questions (e.g., "Purple" for "What's your favorite color?")
  • Store recovery codes in your password manager
  • Register multiple 2FA methods (app + SMS + backup codes)
  • Never share recovery information via email
