TASK 3: PASSWORD MANAGEMENT

With dozens of online accounts, managing passwords securely is challenging. Password managers and two-factor authentication (2FA) provide robust solutions:

Password Managers

These tools generate, store, and autofill complex passwords across all your devices:

Bitwarden

Open-source password manager with free and premium plans. Works across all platforms with secure sharing features.

Visit Site

LastPass

User-friendly interface with emergency access and dark web monitoring. Free version available.

Visit Site

1Password

Premium solution with travel mode and item categories. Excellent family sharing options.

Visit Site

Key Features of Password Managers:

✓ Generate and store unlimited strong passwords
✓ Autofill login credentials across devices
✓ Secure sharing of passwords with family/team
✓ Dark web monitoring for compromised credentials
✓ Encrypted storage for notes and documents

Two-Factor Authentication (2FA)

Add an extra layer of security beyond passwords:

Method How It Works Security Level
SMS Codes Text message with verification code Basic (vulnerable to SIM swapping)
Authenticator Apps Time-based codes (Google Authenticator, Authy) Strong
Security Keys Physical devices (YubiKey, Titan) Very Strong (phishing-resistant)
Biometrics Fingerprint or facial recognition Strong (device-dependent)

Best Practices for Password Management

  • Use a different password for every account
  • Enable 2FA on all important accounts (email, banking, social media)
  • Regularly update your master password (every 3-6 months)
  • Set up emergency access for your password manager
  • Never share your master password or 2FA codes
  • Use biometric locks on mobile password manager apps
  • Audit your passwords periodically for duplicates or weak ones

What To Do If Your Password Is Compromised

  1. Immediately change the password for the affected account
  2. Change passwords for any accounts using the same credentials
  3. Enable 2FA if not already active
  4. Check Have I Been Pwned for other breaches
  5. Review account activity for suspicious actions
  6. Update security questions if they were also compromised
