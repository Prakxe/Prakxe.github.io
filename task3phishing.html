TASK 3: PHISHING INFRASTRUCTURE

Phishing attacks require sophisticated infrastructure to appear legitimate. Attackers use various tools and techniques to create convincing fake websites, emails, and communications. Understanding this infrastructure helps you recognize phishing attempts more effectively.

IMPORTANT NOTE

The information below is for educational purposes only. Understanding attacker methods helps in defense, but never attempt to recreate these techniques.

1. Domain Spoofing

Attackers register domains that look similar to legitimate ones (e.g., "paypa1.com" instead of "paypal.com").

  • Uses homograph attacks (replacing letters with similar-looking characters)
  • Adds subdomains (e.g., "paypal.security-alert.com")
  • Uses international domain names with foreign characters

2. Email Spoofing

Forging email headers to make messages appear from trusted sources.

  • Uses SMTP vulnerabilities to fake sender addresses
  • Creates display names that mimic real contacts
  • Uses compromised accounts to send from real addresses

3. Fake Websites

Hosting replica websites to harvest credentials.

  • Uses free or compromised hosting services
  • Implements SSL certificates to appear secure
  • Clones legitimate sites with minor changes

4. Malware Delivery

Systems to distribute malicious payloads.

  • Uses cloud storage for hosting malicious files
  • Embeds malware in documents (PDFs, Word files)
  • Uses exploit kits on compromised websites

5. Data Collection

Systems to harvest and process stolen data.

  • Uses web forms that submit to attacker servers
  • Implements automated credential processing
  • Uses Telegram bots or other messaging for alerts

6. Evasion Techniques

Methods to avoid detection by security systems.

  • Uses URL shorteners and redirects
  • Implements geofencing to show different content
  • Uses JavaScript to hide malicious elements

How to Identify Phishing Infrastructure:

  • Check domain names carefully - Look for subtle misspellings
  • Inspect email headers - Verify the actual sender address
  • Hover over links - Check where they actually lead
  • Look for poor SSL implementation - Check certificate details
  • Verify website design - Look for inconsistencies with official sites
  • Be wary of urgency - Phishing often creates false urgency
