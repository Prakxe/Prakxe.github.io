1. What is the minimum recommended length for a strong password?
Correct! 12 characters is the current security standard as it dramatically increases the time needed for brute-force attacks.
Incorrect. The correct answer is: 12 characters.
2. Which of these is the strongest password?
Correct! 'J7#kL9!pQr2*' is strongest because it's random, contains mixed characters, and is sufficiently long.
Incorrect. The strongest password is the random one with mixed characters.
3. What is the main benefit of using a password manager?
Correct! While all are true benefits, the main security advantage is generating and storing unique, complex passwords for each account.
Incorrect. The main security benefit is generating and storing unique, complex passwords.
4. Which two-factor authentication method is most secure?
Correct! Physical security keys provide the highest level of protection as they're immune to phishing and SIM-swapping.
Incorrect. Security keys (like YubiKey) are the most secure two-factor authentication method.
5. What should you do if you suspect a password has been compromised?
Correct! You should immediately change compromised passwords on all accounts using them to prevent credential stuffing attacks.
Incorrect. You should change compromised passwords immediately on all accounts using them.
