KNOWLEDGE TEST

This quiz will test your understanding of phishing awareness concepts covered in previous tasks. Select the best answer for each question. You'll receive immediate feedback after submitting your answers.

1. What is the most common characteristic of a phishing email?
Correct! While phishing emails often contain spelling mistakes and come from unknown senders, the most common characteristic is creating a sense of urgency to prompt immediate action.
Incorrect. The correct answer is: It creates a sense of urgency.
2. Which of these is an example of domain spoofing?
Correct! 'microsoft-security-alert.com' is an example of domain spoofing, trying to appear related to Microsoft while being a completely separate domain.
Incorrect. The correct answer is: microsoft-security-alert.com.
3. What should you do if you receive a suspicious email that appears to be from your bank?
Correct! You should always contact the organization directly using a known, trusted phone number or website (not from the email).
Incorrect. The correct answer is: Contact your bank using a known phone number.
4. Which of these is NOT a recommended phishing prevention technique?
Correct! Using the same password for multiple accounts is dangerous because if one account is compromised, all accounts become vulnerable.
Incorrect. The correct answer is: Using the same password for multiple accounts.
5. What is "whaling" in cybersecurity terms?
Correct! Whaling refers to highly targeted phishing attacks aimed at senior executives or high-profile individuals.
Incorrect. The correct answer is: Phishing attacks targeting high-level executives.
