TASK 2: TWO-FACTOR AUTHENTICATION (2FA)

Two-Factor Authentication adds an extra layer of security beyond just a password. Even if someone steals your password, they won't be able to access your account without the second factor.

Why 2FA Matters:

  • Prevents 99.9% of automated attacks
  • Protects against password leaks and breaches
  • Required for many compliance standards
  • Simple to set up but extremely effective
Authenticator Apps

Generate time-based one-time passwords (TOTP) on your smartphone:

  • Works without cellular service
  • More secure than SMS
  • Supports multiple accounts
Security:
SMS/Text Message

Receive one-time codes via text message:

  • No app installation needed
  • Vulnerable to SIM swapping
  • Requires cellular service
Security:
Security Keys

Physical devices that provide the strongest authentication:

  • Phishing-resistant
  • Works even if phone is lost
  • Supports multiple protocols

QR Code
3
Enter Verification Code

4
Save Backup Codes
Store recovery codes in a safe place in case you lose access

Where to Enable 2FA:

  • Email accounts (Gmail, Outlook, etc.)
  • Financial services (Banking, PayPal, etc.)
  • Social media (Facebook, Twitter, LinkedIn)
  • Cloud storage (Google Drive, Dropbox)
  • Work accounts (VPN, email, HR systems)
